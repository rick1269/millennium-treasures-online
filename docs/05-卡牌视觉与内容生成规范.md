# 《千年藏珍》设定评估与 81 张卡牌生成规范

版本：基础版 1.0；整理日期：2026-09-24。此文用于在其他图像或排版软件中制作卡牌。**游戏数据以 `web/catalog.js` 和 `cards/catalog.csv` 为准**；这里给的是原创插画方向和逐张印字清单，不改变现有规则。

## 一、设定分析

### 核心体验

游戏最有辨识度的部分是“每人轮流当拍卖主持人”与同一回合的明拍、暗拍组合。主持人有选品权和正式拍卖佣金，却不能参加这两场拍卖；竞买人要同时权衡金币、资金骰的付款波动和套组价值。红卡把收藏目标变成一个明显的风险选择，适合做视觉焦点。

### 值得保留的设计

1. **公开与秘密竞价交替**：明拍制造桌面互动，暗拍让价格判断有悬念。
2. **同一时代的收藏目标清楚**：1、2、3 星各一张即可成套，重复卡也能享受套组倍率。
3. **主持权均等**：总共 `人数×3` 回合，每人恰好主持三次；单局中的角色变化有节奏。
4. **二次交易与银行出售提供补救路径**：玩家不必只靠正式拍卖获得或处理藏品。

### 优先试玩的问题

| 优先级 | 观察点 | 原因与建议记录的数据 |
|---|---|---|
| 高 | 红卡的得分跃迁 | 按现行公式，1+2+3 星基础值为 60，成套后计 90；再拿红卡后计 200，红卡边际贡献为 110。反过来，只有 1+2 星时拿红卡，该时代从 30 分变为 `70−140=−70`，立刻少 100 分。记录真人红卡成交率、完整套组率、持有未成套红卡的回合数。 |
| 高 | 银行出售是否压过收藏 | 低星和高星倍率最高可达 130%，未成套的卡卖出时会把 10/20/30/40 的基础估值换成更多金币；弃牌区又能洗回牌堆。记录银行卖卡频次、再拍到同张卡的次数、终局金币与藏品分占比。 |
| 中 | 资金骰与佣金是否容易被忽略 | 竞价后实际付款会变化，资金不足还有下回合禁拍。首局玩家可能把报价当成最终价格。建议做一张公共结算提示卡，记录失约次数和规则解释次数。 |
| 中 | 81 张牌的观感重复 | 只有 36 个不同卡名，1/2/3 星每个名字有 3/3/2 张。不同副本需要相同主体、不同角度或局部细节；不要画成不同真实馆藏实物。记录玩家是否能快速凭时代、星级识别卡。 |
| 中 | 历史标签与商业发行 | 部分卡是文学或传说意象，部分被放在游戏时代而非制作年代。现版可作为题材化游戏继续使用；正式教育或商业发行前，应做逐件史实与图像授权核验。具体见文末“历史定位提醒”。 |

机器人试玩只可检验程序运行，不能替代真人平衡测试。一次快速检查中，每种 3–6 席配置各跑 400 局纯机器人对局，终局平均每局仅约 0.07–0.11 张红卡留在玩家手中；这是**当前机器人策略会回避未成套红卡**的结果，不能据此推断真人也会如此。建议先收集约 20 局真人数据，再决定是否调低红卡罚分或调整银行倍率。

## 二、制作与排版总规范

### 2.1 成品尺寸与图层

- 成品：**63 × 88 mm 竖版**；四周各 3 mm 出血，含出血画布为 69 × 94 mm。印刷图至少 300 dpi（含出血约 815 × 1110 px）；文字、星级、编号建议用矢量排版。
- 安全区：所有重要文字距裁切线至少 4 mm；主体器物不要被边框或标题压住。
- 统一图层顺序：背景纹理 → 原创藏品插画 → 深色半透明文字底板 → 时代/星级/名称/估值/编号 → 边框与装饰。
- **图像生成软件只负责插画层**。不要让模型生成中文、星级、钱币数字、编号或博物馆标识；这些要在排版软件里准确录入。
- 所有卡牌共用同一张不透光卡背。红卡只在**正面**以朱红框和红色角标突出，不能用不同卡背泄露身份。

### 2.2 统一卡面版式

| 区域 | 必须呈现的内容 | 视觉要求 |
|---|---|---|
| 顶栏 | 左上时代；右上 `★` 的数量 | 时代标签清晰，星级至少 2 种表达：星数 + 轮廓层级，不能只靠颜色。 |
| 主画面 | 一件藏品或一个文学意象 | 占卡面高度约 50%–55%；暗色展柜、集中光源，主体周围留出文字空间。 |
| 名牌 | 卡名，**逐字使用本文件表格所列名称** | 长名称允许两行，字不能小到难读。 |
| 估值栏 | `基础估值 10/20/30/40 金` | “基础估值”不可省成“成交价”，因为真正付款由拍卖报价与资金骰决定。 |
| 类型栏 | 1–3 星印 `时代藏品`；4 星印 `传奇藏品 · 红卡` | 类型文字没有额外能力含义。 |
| 底栏 | 唯一卡牌 ID，例如 `唐-2-3` | ID 要与网页数据完全相同，不可自行补零或改名。 |

建议版式：深墨绿或近黑背景、铜金铭牌、细线内框；插画偏写实的博物馆概念艺术，纸张与金属有质感，但不要做成复制某一件馆藏摄影作品。1 星用简洁展台，2 星加入器物纹样，3 星用更强的聚光和层次，4 星用朱红边框、局部金箔与“传奇”光晕。红卡的强烈视觉效果不代表额外规则文字。

### 2.3 可直接组合的通用图像提示词

把下面这段与各时代“色彩与纹样”、表格中的“插画画面”拼接后交给图像软件；生成完成再在排版软件叠加“必印文字”。

> 原创中国文物主题桌游卡牌插画，竖版 63:88 构图，深色博物馆展柜，单件主体占画面中央约 60%，精细材质、克制的戏剧性灯光、时代气质鲜明、背景纹样低对比、画面上下预留文字留白。游戏化艺术重构，不宣称为馆藏原物照片，不复刻现存绘画或书法原文。**不生成文字、数字、星星、印章字、logo、水印、边框、手或现代展示标签。**

卡背单独制作：近黑底、对称铜金圆形纹章、中心单字“藏”（在排版软件输入），无时代色、无星级、无红色差异。现有 `cards/print/通用卡背.svg` 可作尺寸和结构参考。

## 四、历史定位提醒与交付检查

### 历史定位

这套牌是“历史题材收藏游戏”，不能直接印成“全部为该朝代现存真品”。尤其需要在正式发行前处理：

- **秦·传国玉玺**：作为传奇印玺意象，不应指定某一现存玉印为传国原玺；故宫关于明代托名玉印的资料提示相关真伪问题。[故宫博物院：明代托名琢制之印](https://www.dpm.org.cn/lemmas/244004.html)。
- **三国·铜雀台瓦砚**：传世瓦砚的年代和真伪复杂，适合画成题材化砚，不标“曹魏原物”。[故宫博物院：误会与想象](https://www.dpm.org.cn/journal/252245.html)。**太平道符、青釭剑、的卢马**也应分别按题材/文学意象处理。
- **唐·兰亭序真迹**：王羲之原迹不存，传世名本为摹本；唐卡的画面应表现收藏传说，而非声称展示真迹。[故宫博物院：《兰亭序》相关研究](https://www.dpm.org.cn/study_detail/98474.html)。
- **元·富春山居图**：元代黄公望画卷作为题材来源可用，但新图应是原创长卷意象。[台北故宫：元黄公望富春山居图](https://digitalarchive.npm.gov.tw/Painting/Content?Dept=P&pid=1193)。
- **民国·张大千泼墨山水、翠玉白菜**：若把“张大千泼墨山水”画成常见的成熟泼彩风格，可参考的代表作品作于 1965 年，已晚于民国纪年；故宫资料将翠玉白菜定在清代。若将来修订时代标签，建议把整组改为“近现代”，并将翠玉白菜移出或换成更合适的近现代藏品。[大都会艺术博物馆：1965 年泼彩山水](https://www.metmuseum.org/art/collection/search/49805)；[台北故宫：翠玉白菜](https://digitalarchive.npm.gov.tw/Collection/Detail/3?dep=U)。

以上时代调整是**未来版本建议**，本文件逐张卡名、ID 和星级保持当前游戏数据不变。馆藏网页可用于核对基本器形与年代；若要直接使用馆藏照片、原作局部或艺术家作品，应另行核对图像授权。

### 交付前逐张检查

1. 总数为 **81 张正面 + 1 张统一卡背**；每时代恰为 1 星×3、2 星×3、3 星×2、4 星×1。
2. 每张卡的时代、卡名、星数、基础估值、红卡类型和 ID 与本表、`cards/catalog.csv` 完全一致。
3. 红卡正面醒目、卡背完全相同；同名副本差异仅为构图，不新增能力或价值。
4. 图层中的中文字、钱币铭文、书画题字、官印和编号由人工排版或逐字校对，不接受生成模型随机输出。
5. 打样检查 63×88 mm 成品、3 mm 出血、至少 4 mm 文字安全边、字体嵌入与色彩模式。
